# RAG-Based Assistant

This module adds a Retrieval-Augmented Generation (RAG) system using LangChain and OpenAI. It pulls real data from `data/` and gives more accurate, grounded responses for dementia caregiving.

## How to run
1. Add your OpenAI key to a `.env` file.
2. Run the chatbot:
   ```bash
   python rag_chat.py
