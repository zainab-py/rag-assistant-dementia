RAG-Based Dementia Care Assistant

An AI-powered dementia support assistant built using Retrieval-Augmented Generation (RAG) to provide context-aware, emotionally sensitive, and personalized interactions for dementia patients and caregivers.

The assistant improves response quality by retrieving relevant patient-related information, routines, memories, and caregiver notes before generating responses. This helps create conversations that feel more supportive, familiar, and consistent over time.

The system retrieves relevant stored information such as caregiver notes, routines, familiar people, or previous interactions before generating a response. This allows the assistant to provide more accurate, comforting, and context-aware communication instead of generic chatbot replies.

Goal

The goal of this project is to make AI-assisted dementia care feel more human, emotionally supportive, and personalized by combining intelligent retrieval systems with conversational AI.
